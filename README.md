# Cloudflare Worker — Studio Video AI v5 Pro

## Cara Deploy ke Cloudflare Workers
1. Masuk ke folder `worker/`
2. Pastikan sudah login Wrangler:
   `npx wrangler login`
3. Deploy Worker:
   `npx wrangler deploy`
4. Salin URL Worker yang muncul (contoh: `https://studio-video-ai-worker.<akun>.workers.dev`) lalu masukkan ke **Pengaturan koneksi** di halaman web.
